## One Line, One Laugh

One deadpan line, 150 characters: a $400 standing desk bought to fix posture, then four hours spent sitting on the floor beside it eating chips — while the Fitbit gives up and logs the whole thing as sleep. One concrete purchase, one ironic twist, one concrete number.

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
